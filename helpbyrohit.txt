# Local AI Model & Application Setup Guide

Hi, fellow teammates! 👋

If you want to use this application, follow the steps below to install the required local AI model and run the application.

## 1. Install Ollama

Ollama allows you to download and run AI models locally on your computer.

### 🐧 Linux

Open the **Terminal** and run:

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

After installation, check whether Ollama was installed correctly:

```bash
ollama -v
```

Then download and run the required model:

```bash
ollama run llama3
```

> **Note:** The first time you run the command, Ollama may need to download the model. This can take some time depending on your internet speed.

---

### 🪟 Windows 11

1. Open the **Ollama website** in your web browser.
2. Download and install Ollama for Windows.
3. Open **Command Prompt (CMD)**.
4. Check that Ollama is installed:

```cmd
ollama --version
```

5. Download and run a model, for example:

```cmd
ollama run phi3:mini
```

You can also use another model available in the Ollama model library, depending on your system's capabilities.

---

# 2. Download the Application Files

To use the application, you need to download these two files:

* `test_1.zip`
* `files.zip`

### Extract the files

1. Extract `test_1.zip`.
2. Extract `files.zip`.
3. **Keep the extracted files in two separate folders.**

Make sure the required files and folders are extracted correctly before continuing.

---

# 3. Run the Application

Open **Command Prompt (Windows)** or **Terminal (Linux)**.

Navigate to the folder containing `app.py`.

Then run:

### Linux

```bash
python3 app.py
```

### Windows

```cmd
python app.py
```

If your system uses `python3` for Python, you can also use:

```cmd
python3 app.py
```

---
